# Results Directory

This directory is intended for the tables, figures, and other derived outputs generated by the reproducibility notebook.

The results in this directory should be treated as **derived outputs**. The raw Instacart source data are not stored here.

## Generated outputs

Depending on the stage of execution, the reproducibility workflow generate outputs including:

- Primary holdout model-performance tables
- Traditional baseline cross-validation results
- Dual-Timescale cross-validation results
- Statistical comparison results
- Sequence-length sensitivity results
- Class-imbalance robustness results
- Feature-correlation outputs
- Feature-importance and SHAP outputs
- Publication/reproducibility figures

## Evaluation metrics

Reported model evaluation includes:

- ROC-AUC
- PR-AUC
- Precision
- Recall
- F1-score
- Matthews Correlation Coefficient (MCC)

## Reproducibility note

The primary experiment uses a user-level holdout test set that retains the natural class distribution. Training-only class balancing is applied where specified in the notebook.

The sequence-length sensitivity analysis is retrospective and does not replace or retune the predefined primary `T = 50` holdout experiment.

Execution time can vary substantially across hardware. Timing results should therefore be interpreted as environment-dependent rather than expected to reproduce exactly on another system.
