# Dataset Setup

This repository does **not** redistribute the raw Instacart dataset.

The experiments use the **Instacart Online Grocery Shopping / Market Basket Analysis dataset**, containing repeated order histories for more than 200,000 users and more than three million orders.

## Required source files

Obtain the original Instacart dataset from its authorised source. Keep the original CSV filenames unchanged.

Before running the reproducibility notebook, place the required source CSV files in the local input-data directory configured in the notebook.

A typical local structure is:

```text
data/
├── orders.csv
├── order_products__prior.csv
├── order_products__train.csv
├── products.csv
├── aisles.csv
└── departments.csv
```


## Important

- Do not commit the raw dataset to this GitHub repository.
- Do not modify the original source CSV files before running the notebook unless explicitly instructed.
- Check the notebook's configuration/path cell before execution and make sure it points to your local `data` directory.
- Derived features, train/test partitions, model outputs, tables, and figures are generated by the reproducibility workflow.

## Prediction target

For the modelling workflow:

- `y = 1` indicates that another observed order follows the current customer order.
- `y = 0` indicates that the current order is the customer's final observed order in the available data.

The Instacart dataset does not provide explicit loyalty-program or subscription-status variables. Repeated transactional behaviour is used to study customer continuation and engagement patterns.
